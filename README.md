# gps-compare

Локальное приложение с веб-интерфейсом для сравнения координат и времени устройств УКУС‑ПИ 02ДМ и МНАВ. Опорный источник — УКУС. Дополнительно можно сравнивать время с интернет-сервером NTP.

Приложение работает на компьютере в сети устройств: браузер показывает результаты, а Node.js выполняет запросы UDP и принимает NMEA по TCP. Внешние JavaScript-библиотеки и установка npm-зависимостей не требуются.

## Возможности

- Разность координат: горизонтальное расстояние, север, восток и высота при подтверждённой системе высот.
- Учёт измеренного взаимного положения антенн.
- Разность времени по NTP, задержки, СКО, RMSE, процентили и относительный дрейф.
- Координаты УКУС через экспериментальный протокол ТО UDP/10554.
- NMEA МНАВ через TCP/6006: GGA, RMC, GSA, GSV и VTG.
- Таблицы спутников, уровни сигнала и участие в решении при наличии соответствующих полей.
- Скорость в км/ч только при фактическом получении достоверного значения RMC/VTG.
- Сохранение CSV, исходного NMEA, JSON и самостоятельного HTML-отчёта с графиками. HTML можно распечатать в PDF.

## Требования

- Node.js 22 или новее; рекомендуется Node.js 24.
- Windows, Linux или macOS.
- Доступ компьютера к устройствам по IPv4. Для внешнего NTP нужен доступ в интернет.

## Быстрый запуск

```bash
git clone https://github.com/ProshkinM/gps-compare.git
cd gps-compare
node server.mjs
```

Откройте [http://127.0.0.1:8765](http://127.0.0.1:8765). В Windows также можно запустить `start.cmd` двойным щелчком.

1. Введите IP УКУС, МНАВ и имя интернет-сервера NTP. Предзаполненные локальные адреса — примеры; замените их адресами своих устройств.
2. Включите навигацию и укажите TCP-порт GPS МНАВ, обычно **6006**.
3. Установите антенны неподвижно. При необходимости задайте смещение антенны МНАВ относительно УКУС: север, восток и высота, в метрах.
4. Оставьте систему высоты УКУС «Не подтверждена», пока не установите её по настройкам или документации устройства.
5. Укажите условия испытания и заводские номера для отчёта, затем нажмите «Начать измерение».
6. Для финального отчёта остановите тест, дождитесь завершения запросов и скачайте нужные файлы.

Консоль приложения должна оставаться открытой. Выход — `Ctrl+C`. Закрытие вкладки не останавливает измерение. Сон или выключение компьютера прерывают испытание. При обновлении остановите старую версию перед запуском новой.

## Порты и конфигурация

| Назначение | По умолчанию |
|---|---|
| Веб-интерфейс | `127.0.0.1:8765` |
| NTP всех источников | UDP/123 |
| Чтение ТО УКУС | UDP/10554 |
| NMEA МНАВ | TCP/6006, настраивается в интерфейсе |

Управление УКУС должно быть разрешено на используемом порту Ethernet. Приложение реализует только чтение известных блоков состояния. Поддержка автономного опроса без запущенной ТО требует проверки на конкретном устройстве.

Переменные окружения:

| Переменная | Значение |
|---|---|
| `PORT` | Порт HTTP, по умолчанию `8765` |
| `NTP_PORT` | Порт NTP для стенда/перенаправления, по умолчанию `123` |
| `NTP_DATA_DIR` | Каталог результатов, по умолчанию `data` рядом с приложением |

Пример для PowerShell:

```powershell
$env:PORT = '8766'
node server.mjs
```

## Как читать результаты

Разность рассчитывается как **МНАВ − УКУС**. Положительная разность времени означает, что МНАВ опережает УКУС; положительные север/восток — что координата МНАВ смещена в соответствующем направлении. Введённое положение антенн вычитается из разности.

Среднее горизонтальное расстояние включает разброс. Длина среднего вектора север/восток показывает устойчивую составляющую смещения. Значения относятся к сравнению с УКУС, а не к абсолютной точности относительно геодезического пункта.

## Файлы результатов

Каждый запуск получает отдельный идентификатор. В каталоге `data` сохраняются:

| Суффикс | Содержимое |
|---|---|
| `.csv` | NTP: все ответы, ошибки и временные метки t1–t4 |
| `.json` | Настройки испытания |
| `.navigation.csv` | Координаты, разности, качество NMEA и причины исключения пар |
| `.navigation.jsonl` | Подробные циклы с исходными ответами ТО и спутниками |
| `.satellites.csv` | История спутников обоих устройств |
| `.nmea.log` | Время поступления на ПК и исходные строки NMEA |
| `.report.json` | Сводка результатов |
| `.report.html` | Самостоятельный отчёт с графиками и таблицами |

CSV: UTF‑8 с BOM, разделитель — запятая, десятичный разделитель — точка. Файлы отчётов создаются при штатной остановке и при скачивании. Во время теста отчёт помечается промежуточным. После аварийного закрытия финальный отчёт может отсутствовать, но ранее записанные журналы остаются.

Результаты предыдущих запусков не загружаются обратно в интерфейс. Сохранённый HTML можно открыть самостоятельно. Журналы и отчёты исключены из Git через `.gitignore`.

## Ограничения

- Время сравнивается через NTP с программными метками. В результат входят сеть и ОС; точность UTC/1PPS этим методом не подтверждается. Постоянная асимметрия сети не устраняется усреднением.
- Координаты сопоставляются по близости поступления на ПК, без подтверждённой общей эпохи GNSS. Используйте режим для **неподвижных антенн**.
- Профиль ТО экспериментальный, рассчитан на **CSM24 04.08 / NV08C 07.03**. Достоверность координат УКУС и его система высот не расшифрованы. Программа не выдаёт метрологическое заключение.
- Каналы УКУС 1–31 декодированы экспериментально. Канал 32 и признаки участия спутников УКУС в решении неизвестны.
- Полная таблица МНАВ требует GSV; признаки использования — GSA. Число каналов, сигналов и используемых спутников — разные показатели.
- Скорость УКУС не идентифицирована. Для МНАВ скорость не вычисляется из изменения координат: при отсутствии переданного значения карточка скрыта.
- Приложение слушает только loopback. Данные остаются в локальных файлах. Классический NTP здесь используется без NTS; для испытаний выбирайте контролируемую сеть.

Подробности форматов: [docs/protocol.md](docs/protocol.md).

## Разработка и проверки

```bash
node --test test/*.test.mjs
```

Или `npm test`, если npm доступен. Установка пакетов не нужна. Тесты используют локальные имитаторы TCP/UDP на динамических портах, проверяют NTP, NMEA, формат ТО, сравнение координат, спутники и экспорт отчётов. Они не обращаются к реальным устройствам и интернет-серверам.

**Все пакетные fixtures и координаты в тестах синтетические.** Исходные захваты сети, реальные измерения, координаты установки и файлы пользователей не входят в репозиторий.

GitHub Actions запускает проверки на Windows и Linux с Node.js 22 и 24.
